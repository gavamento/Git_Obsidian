# Git_Obsidian

ObsidianノートアプリケーションのためのGitリポジトリです。

## 概要

このリポジトリはObsidianで作成したノートやドキュメントを管理するためのものです。Gitを使用してノートの履歴を追跡し、バックアップを行います。

## 構成

- `.obsidian/` - Obsidianの設定ファイル
- `notes/` - ノートを保存するフォルダ
- `attachments/` - 画像やファイルなどの添付ファイル

## 使い方

1. Obsidianアプリをインストールします
2. このリポジトリをクローンします
   ```bash
   git clone https://github.com/gavamento/Git_Obsidian.git
   ```
3. Obsidianで「既存のフォルダを開く」を選択し、クローンしたフォルダを開きます
4. ノートを作成・編集します
5. 変更をコミットしてプッシュします

## 注意事項

- `.gitignore`により、ワークスペースやキャッシュファイルは追跡されません
- プライベートな情報を含むノートを扱う場合は、リポジトリの可視性に注意してください
